### **Performance Analysis Dashboard - Power BI**

As part of my data visualization and business intelligence journey, I developed an interactive **Performance Analysis Dashboard** using **Power BI** to track key performance metrics for a company. This project aimed to create a comprehensive tool for business stakeholders to make data-driven decisions by visualizing and comparing various performance indicators such as **gross profit**, **sales**, **quantity**, and **account profitability**, segmented by **time**, **region**, and **other business dimensions**.

---

### **Key Highlights of the Project:**

- **Interactive Dashboard Design:**  
  The dashboard includes dynamic **performance cards** displaying key metrics like **gross profit**, **sales**, and **quantity**. These cards interact with the entire dashboard, allowing users to filter and drill down into different dimensions, such as **time periods** (e.g., YTD vs. PYTD), **regions**, and **accounts**.

- **Comparative Analysis of Metrics:**  
  Key performance metrics like **gross profit** and **sales** are compared month-over-month and year-to-date, providing insightful trends for decision-makers. The dashboard also allows users to compare **current performance** with **prior year performance**.

- **Geographical and Account Segmentation:**  
  Integrated **scatter plots** and **tree maps** to analyze performance by **account profitability** and **country**. The dashboard provides a detailed breakdown of performance by region, and highlights the **bottom-performing countries** in terms of gross profit and sales, offering valuable insights for resource allocation.

- **Advanced Data Modeling and DAX Implementation:**  
  I built an efficient **data model** that integrated various datasets (sales data, region data, time dimensions) to allow seamless interactions between multiple performance metrics. I implemented custom **DAX (Data Analysis Expressions)** measures to calculate key indicators like **YTD**, **PYTD**, and **gross profit percentages**, enabling dynamic reporting and comparative analysis across time periods.

- **Time Intelligence and Trend Analysis:**  
  Leveraging Power BI’s **time intelligence functions**, I enabled the dashboard to calculate and display **YTD** and **PYTD** metrics, empowering stakeholders to evaluate trends and make timely decisions. The dashboard includes various **trend lines** and **line charts**, providing a clear picture of how business performance evolves over time.

- **Data Transformation and Cleansing:**  
  Using **Power Query**, I cleaned and transformed raw data from different sources into a structured format. This step ensured the data was accurate and ready for analysis, with proper handling of missing values, aggregations, and business rules applied for accurate reporting.

### **Technical Skills and Tools Used:**

- **Power BI:**  
  - **DAX** for custom measures and calculated columns.
  - **Power Query** for data transformation and cleaning.
